# 分类标签

技能使用五个规范分类角色的称谓。本文件将这些角色映射到本仓库问题跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的称谓 | 本文档中的称谓 | 含义                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue                    |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息                    |
| `ready-for-agent`          | `ready-for-agent`    | 已充分明确，可供 AFK 智能体处理             |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现                              |
| `wontfix`                  | `wontfix`            | 不会处理                                   |

当技能提及某个角色（例如“应用 AFK 就绪分类标签”）时，请使用此表中对应的标签字符串。

将右列改成你实际使用的词汇即可。
